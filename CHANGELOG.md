# Changelog

This project follows semantic versioning; see `docs/versioning.md`.

## 0.1.0 - 2026-08-01

- Added typed reconciliation models, deterministic diagnostics, secure SQL
  validation, and a read-only DuckDB adapter.
- Added Python facade and console, JSON, and Markdown reports.
- Added Typer CLI commands with YAML configuration and stable exit codes.
- Added SQL-only dbt key/measure macros, a normalized generic test, and DuckDB
  parity fixtures.
- Added five typed, scoped MCP tools with limits, redaction, and sanitized traces.
- Added the diagnosis-agent skill and deterministic behavior evaluator.
- Added standalone CLI/MCP fanout, date-boundary, and SCD2 diagnostic interfaces.
